# Мята и пион

Сайт-визитка цветочной мастерской в Минске. Учебный проект.

**Тип:** сайт · визитка · одностраничник (+ страница документов)
**Сайт:** https://salzy007.github.io/myata/
**Репозиторий:** https://github.com/Salzy007/myata

## Что на сайте

- Первый экран с кнопкой звонка, анимацией лепестков и фото в арке
- Статус «сейчас открыто / закрыто» по минскому времени
- Подбор букета за 3 вопроса: повод, бюджет, цвета
- О магазине, преимущества
- Каталог из 6 букетов: фильтр по цене, избранное (сохраняется в браузере), окно заказа
- Мобильное меню-кнопка
- Корзина: количество, сумма, сохраняется в браузере; оформление заказа (адрес, дата, время, открытка, оплата) и отправка в WhatsApp или по телефону
- Отзывы: форма с оценкой звёздами (отправка через Formspree)
- Частые вопросы, контакты, соцсети
- Подвал с реквизитами продавца (требования Беларуси)
- Страница документов: персональные данные, cookie, условия продажи

## Структура папки

```
myata-i-pion/
├── index.html        ← готовый сайт, его загружаем на GitHub
├── img/              ← фото букетов
├── src/
│   ├── template.html ← исходник: правки делаем здесь
│   └── build.py      ← собирает index.html из исходника и фото
├── README.md         ← этот файл
└── CLAUDE.md         ← правила проекта для Claude
```

## Как обновить сайт

1. Поправить `src/template.html` (или попросить Claude).
2. Собрать: в папке проекта выполнить `python src/build.py`.
3. Загрузить новый `index.html` на GitHub: Add file → Upload files → Commit changes.
4. Через 1–2 минуты открыть сайт и нажать Ctrl+F5.
